# Как помочь проекту

- **Плохо распознало или перепутало менеджера и клиента?** Откройте issue «Ошибка»: стерео или моно, какая телефония, входящий или исходящий звонок. Не прикладывайте записи с персональными данными.
- **Новая выгрузка телефонии.** Синонимы колонок и признаки оператора — `src/import/sources.ts`, тест — `test/core.test.ts`.
- **Новый API телефонии или CRM.** Клиент — `src/import/telephony.ts` или `src/integrations/crm.ts`; все запросы только через `netFetch` (так их видит счётчик и блокирует офлайн-режим); тест на локальном сервере — `test/integrations.test.ts`.
- **Новый шаблон скрипта.** `src/analyze/scripts.ts`: пункты с подсказкой «что считается выполнением», весом и обязательностью.

Перед pull request: `npm run typecheck && npm test`. Если меняли распознавание — `node test/e2e.mjs`, если промпт или правила оценки — `npm run eval` (нужна модель: `zvonki models`).
